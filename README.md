# Reflect — Security-First Agentic Personal Journaling App

Reflect is a production-grade, security-hardened personal journaling web application powered by **Google Gemini 3.7 Flash** and **Google Cloud Firestore**. It introduces a continuous conversational reflection companion with an asynchronous long-term memory layer, structured on-demand psychological insights, and proactive check-in nudges.

---

## 1. Threat Modeling & Security Architecture

### Core Threats & Mitigations
| Threat Vector | Severity | Mitigation Strategy |
|---|---|---|
| **Cross-Tenant Data Leakage** | Critical | Strict Attribute-Based Access Control (ABAC) in `firestore.rules`. Enforces `request.auth.uid == userId` for all paths under `/users/{userId}/**`. Global collection reads/writes are denied. |
| **API Key & Secret Exposure** | Critical | 100% server-side Gemini SDK calls via Express backend endpoints. `GEMINI_API_KEY` is loaded from Google Cloud Secret Manager / environment variables at runtime. Zero client-side API keys. |
| **Prompt Injection via Journal Narrative** | High | Strict input sanitization, max character bounding, distinct markdown context boundary markers (`=== USER MEMORY SUMMARY ===`), and strict JSON response schemas for analytical queries. |
| **Context Window Token Runaway** | Medium | Tiered RAG architecture: maintains a compressed running profile summary (`<1500` tokens) updated asynchronously, combined with only the last 3–5 recent entries for conversational recency. |
| **Unauthorized Proactive Nudge Triggers** | Medium | Scheduled check-in job is bound to a dedicated Cloud Run / Cloud Scheduler service account with least-privilege IAM permissions (Firestore read on `users/*/entries`, write on `users/*/nudges`). |

## 2. Firestore Data Model & Schema Isolation

All user documents reside in private sub-trees partitioned by authenticated Firebase UID:

```
users/
└── {uid}/
    ├── profile/
    │   └── summary                 # Asynchronous running memory layer (<2000 tokens)
    ├── entries/
    │   └── {entryId}               # Individual reflections, thoughts, and Gemini dialogue turns
    ├── insights/
    │   └── {insightId}             # Structured psychological pattern & mood trend reports
    └── nudges/
        └── {nudgeId}               # Proactive check-in prompts generated by scheduler
```

### Firestore Security Rules (`firestore.rules`)
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Strictly isolate all documents under users/{userId} to the authenticated owner
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }

    // Explicitly deny any access outside the authenticated user's tree
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

## 3. Architecture & Memory / RAG Flow

```
+-------------------------------------------------------------------------------+
|                                 CLIENT (SPA)                                  |
|  - Google Sign-In / Firebase Auth                                             |
|  - Real-time Firestore Subscriptions (Scoped to users/{uid}/**)               |
|  - Daily Reflection Chat, Archive Search, On-Demand Insights, Nudge Banner    |
+---------------------------------------+---------------------------------------+
                                        | POST /api/journal/* (JSON Payload)
                                        v
+-------------------------------------------------------------------------------+
|                            EXPRESS BACKEND (Node.js)                          |
|  1. /api/journal/chat                                                         |
|     - Reads client-provided authenticated summary + 3-5 recent entries        |
|     - Delivers mindful, empathetic reflection via Gemini 3.7 Flash            |
|                                                                               |
|  2. /api/journal/update-profile                                               |
|     - Asynchronously distills new conversation into running profile summary   |
|                                                                               |
|  3. /api/journal/generate-insights                                            |
|     - Returns structured JSON metrics (mood trends, themes, notable shifts)   |
|                                                                               |
|  4. /api/journal/generate-nudge                                               |
|     - Simulates Cloud Scheduler proactive check-in prompt generation          |
|                                                                               |
|  5. /api/journal/analyze-sentiment                                           |
|     - Derives emoji, color tone code, harmonic score, and mindful summary     |
+---------------------------------------+---------------------------------------+
                                        | @google/genai (GEMINI_API_KEY)
                                        v
+-------------------------------------------------------------------------------+
|                         GEMINI 3.7 FLASH (Google AI)                          |
+-------------------------------------------------------------------------------+
```

---

## 4. Secret Management & Cloud Configuration

- **`GEMINI_API_KEY`**: Stored in Google Cloud Secret Manager and injected at runtime into Cloud Run container environment variables.
- **Firebase Configuration**: Provisioned via Google AI Studio Firebase integration (`firebase-applet-config.json`).
- **Cloud Scheduler & IAM**: Configured with a dedicated service account having minimal Firestore and Secret Manager roles.
